# 反模式库(anti-patterns)

被 skill-doctor 阶段① Gate(AP1-AP3 危险模式判定)与阶段 C(全部 15 条)加载。每条三段式:**触发条件 → 误报风险 → 豁免清单**。
判定流程:先查触发条件(确定性模式匹配),命中后再查豁免清单;**豁免清单任一条件满足即豁免;某个条件无法机械判定时视为不满足(不豁免)**。
无触发条件命中 → 该条不报告。

## 严重度映射

| 级别 | 含义 | 报告动作 |
|------|------|----------|
| 🔴 高风险 | 执行安全,可致数据/凭据损失 | P0,并入 Gate Result |
| 🟡 工程可靠性 | 可能损坏工作成果或行为不可靠 | P1 |
| 🟢 质量 | 影响维护/协作,非致命 | P2 |

## AP1 无限文件删除 🔴
- **触发条件**:指令含递归删除模式(`rm -rf`、`fs.rm(recursive:true)`、`删除所有/全部文件`),且未限定目标范围
- **误报风险**:清理 build/、node_modules/、临时目录的正常指令同样含 rm -rf
- **豁免清单**:
  1. 目标限定在明确目录(如 build/、temp/)
  2. 含 dry-run 或确认提示
  3. 不触及用户数据/文档目录

## AP2 裸 curl|bash 🔴
- **触发条件**:含 `curl <URL> | bash` / `curl <URL> | sh`,且 URL 不在白名单
- **误报风险**:`curl -I url` 探测、下载后先审查再执行属正常做法
- **豁免清单**:
  1. URL 在 security_exemptions 白名单
  2. 或先下载并校验哈希
  3. 或执行前有内容审查步骤

## AP3 敏感文件读取 🔴
- **触发条件**:指令含读取 `~/.ssh/*`、`.env`、`credentials`、密钥/令牌文件内容
- **误报风险**:读取 .env.example、仅 stat 检查文件是否存在属正常
- **豁免清单**:
  1. 或文件在 security_exemptions 白名单
  2. 或用户本轮显式授权
  3. 或仅读文件名/元数据不读内容
  4. 或目标为 .env.example / .env.production 等示例/模板文件(非真实凭据)

## AP4 无输入验证执行 🟡
- **触发条件**:外部输入(用户参数/文件内容/环境变量)直接拼入命令或代码,无校验、无转义
- **误报风险**:内部常量拼接、固定参数调用不构成;引号转义到位不算
- **豁免清单**:
  1. 输入有类型/格式校验或白名单过滤
  2. 或输入来自可信内部来源
  3. 或仅作展示不执行

## AP5 硬编码密钥 🟡
- **触发条件**:出现疑似密钥/令牌字面量(API key、password、token、secret = 具体值)
- **误报风险**:示例值、占位符(YOUR_API_KEY)、测试 fake 值不构成
- **豁免清单**:
  1. 值引用环境变量或配置文件
  2. 或明确标注示例/占位
  3. 或为可公开的测试凭据

## AP6 递归修改无边界 🟡
- **触发条件**:递归遍历目录并修改文件,无目录范围/最大深度/文件数上限
- **误报风险**:限定深度的小范围遍历、只读遍历正常
- **豁免清单**:
  1. 限定目录范围
  2. 或含数量/深度上限
  3. 或先 dry-run 展示改动

## AP7 指令职责混杂 🟡
- **触发条件**:description/声明只做 X,正文却含 Y/Z 无关主流程(scope drift)
- **误报风险**:前置准备、清理、收尾等服务于主目标的步骤不算
- **豁免清单**:
  1. 额外步骤服务主目标
  2. 有清晰边界/标题说明
  3. 未改变核心输入输出契约

## AP8 无失败分支 🟡
- **触发条件**:含外部副作用(API 调用/文件写/部署),却无任何失败处理分支
- **误报风险**:纯生成/纯分析类 skill 不要求失败分支
- **豁免清单**:
  1. 无外部副作用(仅内部计算)
  2. 或已有失败提示/回滚
  3. 或失败仅告警不阻断

## AP9 过度宽泛文件匹配 🟢
- **触发条件**:写操作使用过宽 glob(`**/*`、`*.*`、`所有文件`)且无排除清单
- **误报风险**:只读扫描全目录、搜索定位正常
- **豁免清单**:
  1. 仅读操作
  2. 或含排除清单(ignore/exclude)
  3. 或目标目录明确收窄

## AP10 输出格式不稳定 🟢
- **触发条件**:输出在不同分支/路径下结构不一致(无固定模板),且被其他 skill 调用
- **误报风险**:面向人可读的对话输出不强制固定格式
- **豁免清单**:
  1. 仅人读不机器解析
  2. 或已有固定输出模板
  3. 或由调用方约定格式

## AP11 重复 Duplication 🟢
- **触发条件**:同一含义(规则/约束/定义)在 ≥2 处独立表述(措辞不同或整段复制),且无指针引用关系
- **误报风险**:不同语境引用同一规则不算;标题与正文的正常呼应不算;共置的「定义-示例」配对不算
- **豁免清单**:
  1. 一处为唯一权威源,他处仅指针引用(「见 X §N」)
  2. 或措辞不同且各有侧重
  3. 或属共置的「定义-示例」配对(非重复)

## AP12 无操作行 No-Op 🟢
- **触发条件**:存在模型默认就执行的表述(弱指令「请认真思考/确保正确」、默认行为重述),删掉该行行为不变
- **误报风险**:强化语气有实际约束力(「写死/强制」)时不算;硬护栏不算
- **豁免清单**:
  1. 删除该行会改变行为(有约束力)
  2. 或属无法正面表述的硬护栏
  3. 或属关键决策的显式编码(防默认漂移)

## AP13 否定式 Negation 🟢
- **触发条件**:非硬护栏的「不要/禁止/别/避免 X」禁令,且无对应的正面替代指令
- **误报风险**:安全护栏(「不要删除用户数据」)属硬护栏,可保留
- **豁免清单**:
  1. 无法正面表述的硬护栏(安全/数据损失边界)
  2. 或禁令后紧跟正面替代指令
  3. 或面向安全/数据损失的硬边界

## AP14 过早完成 Premature Completion 🟢
- **触发条件**:步骤/阶段完成判据模糊(不可核查或非穷尽,如「生成变更清单」而非「每个改到的模型都记入」),诱使提前收尾
- **误报风险**:无步骤序列的纯 reference skill 不适用
- **豁免清单**:
  1. 判据可核查(checkable)
  2. 或判据穷尽(exhaustive)
  3. 或无步骤序列

## AP15 沉积 Sediment 🟢 ⚠️ 静态难判
- **触发条件**:存在明显过期内容(标注「旧/已废弃/不再适用」的段落、与新规则冲突的遗留规则)且未清理
- **误报风险**:向后兼容说明、历史版本备注不算;静态难以判定 → 报告标「需作者确认」
- **豁免清单**:
  1. 有明确版本/迁移说明
  2. 或静态判定不确定 → 转 ⚠️ 需作者确认,不自动拉低
  3. 或属服务于兼容的历史记录

## 判定总则

- 顺序:先触发条件,后豁免清单;触发不命中即跳过
- 豁免清单:**任一条件满足即豁免**;某个豁免条件无法机械判定时视为不满足(不豁免)
- 命中输出格式:`AP# · 严重度 · 证据行号 · 置信度(High/Medium/Low) · 修复方向`
- 🔴 命中且未豁免 → 同时列入 Gate Result 的 BLOCKED 项与 Priority Fixes P0
- 去重:AP1-AP3 命中已列入 Gate Result,阶段 C 的 Findings 不再重复详报,仅标"同 Gate";AP4-AP15 正常详报
